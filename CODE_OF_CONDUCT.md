# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be direct about the code and considerate about the person. Harassment, personal
attacks and bad-faith arguments are not welcome; substantive criticism of the code is.

## Reporting

Report unacceptable behaviour through
[GitHub's private reporting form](https://github.com/Qaaxaap/powerlevel11k/security/advisories/new),
or in a discussion when the report is not sensitive. The maintainer reads every report and
will say what was decided.

## Enforcement

The maintainer may edit or delete comments, close issues and pull requests, or block
accounts, and will explain the reason when doing so.
